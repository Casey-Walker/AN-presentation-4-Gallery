# Where Should a UK Graduate Start a U.S. Analytics Career?

**Business question:** Which U.S. metro areas offer the best combination of
posting volume, salary, and entry-level accessibility for data and
analytics roles, what skills do employers in those metros ask for, and
where should a UK graduate apply first?

## Project Overview

Using a 2026 snapshot of U.S. data/analytics job postings, we filtered the
listings down to analyst, analytics, BI, data science, data engineering,
and reporting roles in the United States, then profiled each metro area on
posting volume, disclosed salary, and how open it is to entry-level
candidates. From there we mined the job descriptions themselves — most
requested skills, topic clusters via LDA, and word clouds — to see what
employers in the strongest metros are actually asking for. The result is a
ranked shortlist of where a UK graduate, new to the U.S. market and
cost-of-living conscious, should focus their job search first.
